Support

A browser that reaches the web only through Tor and reads it with an AI running on your phone. Here is how each part works, and what to try when something does not.

Connecting to Tor

Why is the first connection so slow?

Before Tor can build a single route it has to download the public list of relays — a directory covering roughly nine thousand computers. On a brand-new install none of that is cached, so the first connection commonly takes two to six minutes. It is not the app hanging; the progress bar is reporting Tor's own state.

Every connection after that reuses the cached directory and takes well under a minute. Desktop Tor Browser behaves the same way for the same reason.

Can I use the browser while it is connecting?

No, and that is deliberate. Nothing in the app can reach the network before Tor is carrying traffic — there is no path that would quietly load a page over your ordinary connection instead. The browser appears once circuits are up.

Cancel and Connect

Cancel stops the connection attempt properly: Tor stays running with its network switched off, so nothing can leave the device. Connect resumes from where it stopped rather than starting cold, so it is much quicker the second time.

If you would rather the app waited for you instead of connecting on launch, turn off Connect automatically on that screen.

It never finishes connecting

Some networks block Tor outright — this happens on certain corporate, school and national networks. Try a different network or a mobile connection. Tap Tor logs on the connect screen to see exactly what Tor is reporting; that log is the fastest thing to send us if you need help.

This version does not include bridges or pluggable transports, so it cannot get around a network that blocks Tor deliberately.

Searching

Which search engines can I use?

Onion Search is the default: it asks Ahmia and DuckDuckGo Onion together and merges the two, so the search never leaves the Tor network and still always comes back with something. Ahmia on its own searches onion services, which is how you find a .onion address in the first place. DuckDuckGo Onion is DuckDuckGo's index reached as an onion service. DuckDuckGo is the ordinary one — it answers Tor exit relays without challenging them. All merges DuckDuckGo and Ahmia.

Google, Bing, Brave and Startpage are absent on purpose: all of them answer a Tor exit relay with a challenge page rather than results.

My Ahmia search came back with nothing. What should I use?

Onion Search. An onion index covers tens of thousands of sites rather than billions of pages, so a narrow query can genuinely match nothing there. Onion Search asks Ahmia first and DuckDuckGo's onion service second, and shows both — the onion results when they exist, and an ordinary answer when they do not. Neither request leaves the Tor network.

It also helps to search the way you would an index this size: two or three distinctive words rather than a full sentence.

Can I use a different search engine?

Yes. Open Settings → Search engine → Custom, paste the address of any engine's results page with %s where your words go, and tap Use this engine. Clearnet or onion, either works. A few addresses that are known to work are listed on that screen — tap one to fill it in.

Test engine on the same screen loads the page over Tor and tells you how many results it could read, so you know before you commit.

Can I add my own search engine?

Yes. Settings → Search engine → Custom. Open your engine in any browser, search for the word test, copy the address of the results page, and paste it in — replacing test with %s. Onion addresses are accepted, including http:// ones. There is a Test button that runs a real search and tells you how many results it could read before you commit to it.

The tabs — Web, News, Forums, Books

These narrow your chosen engine to the right kind of site using search operators. If a narrow search finds nothing, the app widens it automatically rather than showing an empty page. Images and video tabs are not offered: the services behind them refuse Tor exit relays, so they would only ever be empty.

Searching is slower than I expect

Every query travels through three relays and back. A few seconds is normal. Ahmia is slower still — its results page is large and it takes two page loads to reach, so give it up to a minute. Onion Search queries two engines one after the other, so allow a little longer again; results from the first appear while the second is still loading.

Onion addresses

What is the onion symbol in the address bar?

It means you are on an onion service — a site reachable only inside the Tor network. There is no exit relay involved at all, and the connection is encrypted and authenticated to the service's own key. That is why an onion address shows the onion mark rather than a padlock, even on http://.

Why does HTTPS-Only not apply to onion sites?

Because it would be pointless and would break them. An onion connection is already end-to-end encrypted and verified against the address itself, with no certificate authority in the picture — which is exactly why most onion services serve plain HTTP.

Security and privacy controls

Security level — Standard, Safer, Safest

Standard lets every site run as built. Safer switches JavaScript off on unencrypted http:// sites and blocks web fonts and autoplaying media everywhere. Safest switches JavaScript off everywhere, including onion services, and blocks inline SVG as well.

The higher levels break more sites. That is the trade they exist to make. A change applies to the next page you open; a page already on screen keeps the rules it loaded with.

HTTPS-Only mode

On by default. An http:// address is upgraded to https:// before the request goes out. If the site has no HTTPS at all, the browser stops and asks rather than sending anything in the clear — where the exit relay, and everyone between it and the site, could read and change it. Continuing writes a per-site exception you can see and revoke in Site settings.

New circuit vs New identity

New circuit changes the route only. Same cookies, same session, same history — a site that knew who you were still does. Use it when a route is slow or an exit relay is being blocked.

New identity changes everything: it closes every circuit and deletes cookies, caches, history, site settings and the Tor log, then returns you to a clean home screen. Anything you were signed in to, you are signed out of.

Both are in the Tor connection screen — tap the status pill at the top of the home screen, or the address bar on any page.

Deleting my data

Settings → Data → Delete browsing data, where you choose what goes. Worth knowing: cookies, caches and site storage are never written to disk in the first place — they live in memory and disappear when the app closes. That screen is for clearing them before then.

Notifications

Websites cannot send you notifications in this browser — the engine has no support for Web Push, so there is nothing to grant or deny. The app itself can optionally tell you when Tor connects or drops while it is in the background; both switches are off by default, in Settings → Data → Notifications.

AI Overview

What is the panel above the results?

A summary of everything a search brought back, written on your phone. Results appear as soon as an engine answers — the summary fills in underneath and never delays them. Where several engines contribute, each gets its own short summary, with the pages it drew on listed as chips you can tap.

It is taking a while

Generating text on a phone takes seconds, not milliseconds, and older devices are slower. The rotating word tells you it is still working. Tap Stop at any time — the results themselves are already there and stay there. You can also switch the overview off entirely in Settings.

The page assistant

The glowing button on a web page

Tap it and the app reads the page before you ask anything: the text the site provides, and — if "Read the screen too" is on — a picture of what is currently on screen, analysed on your device for text, imagery and whether people are pictured. Then ask it anything about the page.

Does the screenshot go anywhere?

No. It is analysed on your device using Apple's Vision framework and discarded. It is never stored and never uploaded. You can turn the feature off in Settings → On-device AI.

Using a cloud model instead

Connecting Gemini, ChatGPT, Claude and others

Tap the pill at the bottom of the home screen, or Settings → the engine row. Choose Cloud, pick a provider, paste your API key and select a model. Your key is stored only on your device and is sent only to that provider.

A connected service is the one thing in this browser that does not go through Tor. It is reached directly, because routing a streaming response through three relays is slow enough to be unusable — which means the provider sees your questions, the page text and your IP address. It is off by default and used only while you have it selected. Switch back to on-device and nothing leaves the phone at all.

Connecting my own server

Choose Custom and give it an address, an optional auth header, a request body containing {prompt}, and the path to the text inside each streamed chunk. The defaults describe an OpenAI-compatible server, which is what llama.cpp's own server speaks — so a model on your own machine usually needs little more than the URL.

Can I use a different local model?

Yes. In the engine picker, On device → Import a .gguf model. Anything llama.cpp can load will work, though larger models are slower and may not fit on older phones. A local model stays local, so it costs nothing in privacy.

Troubleshooting

A page will not load

First check the status pill — if Tor has dropped, nothing will load until it is back, and that is the browser working rather than failing. Otherwise try reload, then New circuit: a slow or blocked exit relay is the single most common cause, and a new route usually fixes it.

A site says my connection is insecure, or blocks me

Many sites treat Tor exit relays with suspicion and will show a CAPTCHA or refuse entirely. A new circuit gives you a different exit and often gets through. Some sites block Tor as a matter of policy and no amount of retrying will help.

An answer stopped halfway

Replies have a length limit that is smaller on devices with less memory. Ask a narrower question, or connect a cloud model for long-form answers.

The app relaunched itself after I changed model

Expected on devices with less memory. Two models cannot be held at once there, so the app restarts to swap cleanly rather than risk being terminated by the system.

Opening links from other apps

DarkDeepWeb registers darkdeepweb://, so another app can hand it a link to open privately — darkdeepweb://open?url=… or darkdeepweb://search?q=…. If Tor is not connected yet the link is held, not dropped, and opens as soon as circuits exist.
